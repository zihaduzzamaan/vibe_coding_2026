# Skill Orchestration Rule

On every prompt:
1. Identify the task domain (UI design, component construction, animations, performance tuning, backend/auth, or debugging).
2. Activate and apply the installed domain skill from `.agents/skills/`.
3. Adhere strictly to the performance standards (`vercel-react-best-practices`, GPU animations in `framer-motion-animator`, and design aesthetics in `ui-ux-pro-max`).
